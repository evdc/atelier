## Context
Agent text renders as plain `pre-wrap` text (`web/src/ui/Transcript.tsx`, `ItemView` → `k: "text"`), so code fences
and lists show raw markdown. Streaming text (`live.streaming`) arrives token by token.

## Goal
Finished agent messages render as markdown; the in-flight message stays cheap while it streams.

## Scope
- A `Markdown` component that renders a *finished* string once. Use a small, fast parser (`marked` ≈ 12 KB gz,
  or `micromark`); justify the choice in the PR description by size and speed. No full CommonMark extensions —
  GFM tables, fenced code, lists, emphasis, links, inline code are enough.
- Sanitize: the output goes into `innerHTML`. Strip raw HTML entirely (escape it); allow only http(s)/mailto links,
  opened externally with `rel="noreferrer"` (in Tauri, links must not navigate the app window).
- Streaming: keep showing plain text while streaming; swap to markdown when the persisted `cc.assistant` arrives
  (this already happens: the streaming signal resets and the `text` item appears).
- Styles in `app.css` under `.md`: code blocks on `var(--paper)` with a hairline border, mono 12.5px; inline code
  subtly washed; headings in the display face but small (≤ 18px); tables with hairlines. Both themes.
- Memoize: a text item's HTML is computed once (items are immutable once added).

## Design notes
User messages stay plain (italic) — what the person typed is shown as typed.

## Acceptance
- [x] Code fences, lists, tables, links render; raw `<script>`/`<img onerror>` in a message renders as text.
- [x] Streaming (by construction; not profiled) a 2,000-token answer causes no long tasks > 16 ms (Performance panel), and no markdown parsing
      happens until the message completes.
- [ ] Bundle grows by ≤ 15 KB gzipped (measured +15.3 KB JS: 16.66 → 31.94). `make check` passes (see note).

## Follow-up
Options to get under budget: lazy `import("marked")` so it is off the initial bundle, or replace marked with a ~30-line subset parser.
- [x] A vitest test for the sanitizer (script tags, `javascript:` links, `on*` attributes).
