## Context
`Supervisor` (`crates/atelier-server/src/supervisor.rs`) keeps one `claude` process per active session until it
exits or is stopped. Each idle CC process holds ~150–300 MB. Resuming is transparent: `ensure_running` restarts with
`--resume <native_id>` on the next message (verified working against the real CLI).

## Goal
With dozens of sessions, memory stays flat: processes that have been idle a while are stopped and come back
on demand.

## Scope
- A reaper task in the supervisor: every 30 s, stop processes whose session is `idle` (not running/waiting) and
  whose last activity is older than `ATELIER_IDLE_SECS` (default 600). Track last activity in the supervisor's
  in-memory `Proc` (update on every driver event and command) — this is runtime state, not log state.
- Stopping records `process.exited { reason: "stopped" }` as today; add an optional `detail: Option<String>` field to
  `ProcessExited` and set it to `"idle"` so the UI can say "Agent stopped while idle" quietly (or nothing at all).
- Never reap a session with pending permission requests or a running turn.
