## Context
`turn.ended.raw` (the CC `result` message) carries `usage` (input/output/cache tokens) and `modelUsage`;
`cc.rate_limit_event` carries subscription window utilization (`five_hour`, `seven_day`, with `resetsAt`).
`cc.system` init carries the model. Today the header shows only turns and cost.

## Goal
At a glance: how much context this session is using, and how close the subscription is to its limits.

## Scope
- Session header meta: context used (latest turn's input + cache tokens) as `96k tokens` like the mockups; model from
  the latest init.
- Sidebar footer (global): 5-hour and 7-day utilization as two small hairline bars (gold under 80%, red above),
  with reset time on hover. Source: the most recent `cc.rate_limit_event` across all sessions — add a tiny
  server view `usage` (a projection keeping the latest event) rather than subscribing to all sessions.
- Keep it quiet: no numbers when unknown.
