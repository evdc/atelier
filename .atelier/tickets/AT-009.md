## Goal
Everything common is one keystroke away, and nothing steals focus unexpectedly.

## Scope
- One global keydown handler (`web/src/lib/keys.ts`) with a declarative table; no per-component listeners.
- `⌘K` command palette: fuzzy-jump to projects and sessions (from the views already in memory — no server
  round-trip), plus actions (New session, Add project, Archive, Interrupt). Simple subsequence matching, ≤ 60 lines.
- `⌘N` new session in the current project; `⌘[`/`⌘]` back/forward; `j`/`k` move through the session list when it
  has focus; `Esc` interrupts a running session when the composer is empty and focused, otherwise blurs.
- `/` focuses the composer. Typing anywhere in a session (no modifier) focuses the composer and inserts the key.
- Show shortcuts in `title` tooltips; a `?` overlay listing them.
- Desktop only: don't show palette hints on touch devices.
