## Context
`session.create` makes a worktree at `~/.atelier/worktrees/<project>/<id>` on branch `atelier/<slug>-<id>` from the
repo's HEAD (`crates/atelier-server/src/workspace.rs`). Nothing shows what changed there, and archiving leaves the
worktree behind.

## Goal
See what a session changed, open it in your tools, and clean it up when done.

## Scope
- RPC `session.changes { session }` → `{ base, files: [{ path, status, added, removed }] }` from
  `git diff --numstat <base>` + untracked files. (An RPC result, not state: it's a computed snapshot of the
  filesystem, like a read. Note this exception in `rpc.rs`.)
- Session header: "N files changed +a −r" that expands into the file list; each file shows its diff on click
  (reuse AT-003's diff view if landed; otherwise plain).
- "Open in…" for desktop clients only: Terminal, editor (`$VISUAL`/`code`/`zed`), Finder. These must run on the
  *client* machine, so they're only offered when the server is local (`url` is loopback). Implement via a Tauri
  command in `app/` (`open_path(kind, path)`) — the first Tauri command; keep it minimal and allowlisted.
- Archive: if the worktree has no uncommitted changes and its branch is merged or has no commits beyond base,
  remove the worktree and branch; otherwise keep both and say so. Append `workspace.removed` (new event kind).
- `project.remove` should refuse while sessions are alive.
