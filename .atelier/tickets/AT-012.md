## Context
The server binds 127.0.0.1 and authenticates with a token from `<home>/token` (`atelier_proto::local`). The web
client reads `{url, token}` from `window.__ATELIER__`, the Vite dev define, or `localStorage["atelier.server"]`
(`web/src/lib/conn.ts: serverConfig`). The phone must reach the desktop's (or a VPS's) server over Tailscale.

## Goal
Reach a server from a phone (or second laptop) on your own tailnet by typing its address. Tailscale is assumed to be
set up already; the tailnet is the network boundary.

## Scope
- Server: `ATELIER_LISTEN_TAILSCALE=1` discovers the tailnet IP (`tailscale ip -4`) and listens there in addition to
  loopback. Never bind 0.0.0.0 by default.
- Auth: the owner token (`<home>/token`) works everywhere. On the tailnet listener only, a hello without a token is
  accepted if `tailscale whois` says the peer belongs to the same Tailscale user as this server's node (cached
  briefly; fails closed). Loopback always requires the token.
- Web: a Settings panel (also shown when `serverConfig()` is null, replacing `Unconfigured.tsx`): server address
  (`host`, `host:port` or `ws://…/ws`), optional token, connection state; saves to `localStorage["atelier.server"]`.

## Acceptance
- [ ] e2e: token accepted; missing token rejected on loopback; trusted tailnet peer accepted and untrusted rejected
      (with an injected fake whois).
- [ ] whois/status parsing unit-tested on captured JSON.
- [ ] `make check` passes.
