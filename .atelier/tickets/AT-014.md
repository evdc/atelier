## Goal
When a session starts waiting on you (or fails) and you're not looking at it, you hear about it once.

## Scope
- Client-side, from the existing all-sessions watch (`App.tsx` → `sessions`): detect transitions into `waiting` or
  `failed` (compare with the previous row). If the document is hidden or that session isn't open, notify.
- Desktop: the Notification API inside the Tauri webview (or `tauri-plugin-notification` if the web API is not
  available in WKWebView — check). Click focuses the app and opens the session.
- Dock badge = number of waiting sessions (Tauri `set_badge_count`; desktop only).
- Coalesce: at most one notification per session per 30 s.
- Mobile push (APNs) is a separate, later ticket: it needs a relay, since the server is on a tailnet.
