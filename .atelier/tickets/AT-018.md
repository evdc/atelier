## Context
Adding a project means typing an absolute path on the server (`ProjectsView.tsx`). The server may be remote, so a
native file dialog on the client is wrong.

## Scope
- RPC `fs.list { path? }` → `{ path, parent, entries: [{ name, is_dir, is_git }] }`, directories only, hidden ones
  excluded unless asked, capped at 500 entries; default path = server user's home. A read-only computed result
  (like AT-010's `session.changes`).
- An inline picker under the path field: breadcrumb + directory list; git repos marked; "Add this folder".
- Suggestions: recently modified git repos under `~/Projects`, `~/src`, `~/code` (if they exist), max 8.

- [ ] Unit test for `fs.list` (temp dir tree). `make check` passes.
