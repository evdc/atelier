## Scope
GitHub Actions on macOS (the primary platform) and Ubuntu (server-only, for the VPS case):
`make check`, `make test`; cache cargo and pnpm. Ubuntu job builds only `crates/*` (skip `app/`, which needs
webkit2gtk). Fail if `web/src/gen` is stale (`make check` already does this).

## Acceptance
- [ ] Green run on a PR; total time < 10 min with warm caches.

## Notes
- `.github/workflows/ci.yml`: `macos` runs `make check` and `make test`; `ubuntu` runs the same targets with
  `CARGO_SCOPE="--workspace --exclude atelier-app"`. `CARGO_SCOPE` is the only Makefile change.
- Caches: Swatinem/rust-cache, and pnpm via setup-node keyed on `web/pnpm-lock.yaml`. Actions are pinned to major
  tags (checkout@v4, setup-node@v4, pnpm/action-setup@v4, rust-cache@v2, dtolnay/rust-toolchain@stable).
- Versions: the repo pins none (no rust-toolchain, .nvmrc, `packageManager` or `engines`). CI uses Node 22, pnpm
  11.5.3 (the local version), and stable Rust. Clippy can start failing when stable moves; a `rust-toolchain.toml`
  would pin it.
- Not verified: the green PR run and the < 10 min warm-cache time, which need a push. The Ubuntu job has not been
  run on Linux here, and no Linux target is installed locally.
