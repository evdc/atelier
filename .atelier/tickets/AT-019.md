## Scope
GitHub Actions on macOS (the primary platform) and Ubuntu (server-only, for the VPS case):
`make check`, `make test`; cache cargo and pnpm. Ubuntu job builds only `crates/*` (skip `app/`, which needs
webkit2gtk). Fail if `web/src/gen` is stale (`make check` already does this).

## Acceptance
- [ ] Green run on a PR; total time < 10 min with warm caches.
