## Context
`atelier-store` group-commits appends on a single writer thread. Subscriptions by exact stream use the
`events_by_stream(stream, seq)` index; prefix subscriptions (`p/<project>/`) range-scan on stream and then sort by
seq, which degrades as a project's history grows.

## Scope
- A `cargo bench`-free benchmark binary (`crates/atelier-store/examples/bench.rs`): append throughput (single and
  128 concurrent appenders), catch-up read speed for exact and prefix filters at 1M events, projection rebuild time.
- Record numbers in this ticket. If prefix catch-up from seq 1 over 100k events in one project exceeds 200 ms, fix it
  — e.g. a `project` column with an index on `(project, seq)`, populated at insert from the stream name — and
  record numbers again.
