Follow-ups to the worktree pool (see DESIGN.md §3).

- Optional per-project `.atelier/setup` script run after a worktree is created or reused (e.g. `pnpm install --offline`),
  since a reused or cloned `node_modules` can lag the lockfile at the new base.
- Seed asynchronously (or show "preparing workspace") if the clone of a large `target/` is noticeable at session start.
- Pool size and seed directories configurable per project.
- Prune pooled worktrees on project removal.
