## Context
Search is how an agent finds the session that already knows something, which is the emergent specialist from
DESIGN §11.1. AT-024 builds `search.query`; this exposes it to agents. AT-025's hybrid ranking flows through
unchanged when it lands.

## Scope
- Tool `search { q, project?, include_archived? }`. `project` defaults to the caller's; `"*"` searches all projects.
- Output is text, at most 10 sessions:
  ```
  7f3a · Fix WAL checkpoint · idle · 2d ago · 4 hits
    #18233 agent: …the writer batches commits under «2 ms» when…
  ```
  The `\u{2}…\u{3}` marks become `«…»`. Then one line of guidance: "read with read(session, around=<seq>), or
  ask(to, question)".
- Exclude the caller's own session.
- Pre-allowed (add it to the `--allowedTools` list).
- Extend the appended system prompt by one clause: search before spawning or re-deriving.

## Acceptance
- [ ] e2e: session B says a distinctive word; agent A calls `search` for it and gets B back, with a `#seq` that
      `read { around }` resolves.
- [ ] Unit test for the text formatting, including the mark conversion and own-session exclusion.
- [ ] `make check` and `make test` pass.
