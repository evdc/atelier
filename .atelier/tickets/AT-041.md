## Context
Columns and statuses are project config in `.atelier/board.json` (AT-037), written by `board.update` (AT-038).
People shouldn't have to hand-edit JSON to change their workflow. This ticket adds an editor on the board that
produces the same file.

Read first: AT-037 (config shape, validation rules), AT-038 (`board.update`); AT-039's `TicketsView` and
`ui/board/`; `web/src/ui/Settings.tsx` and `styles/settings.css` (existing form idioms).

## Scope
- **Entry point**: an "Edit columns" button in the board header. It opens a panel (a side sheet on desktop, full
  screen on a phone) that edits a **draft** copy of the config. Nothing is written until **Save**; **Cancel**
  discards.
- **In the panel**:
  - **Columns**, in order:
    - rename;
    - reorder with up/down buttons (keyboard-friendly; drag can come later);
    - toggle `collapsed`;
    - delete;
    - add.
    Each column lists its statuses as chips: remove a chip; add one from the known statuses or type a new one.
    The first chip is labelled "set when dropped here", and you can reorder chips to change it.
  - **Statuses**: the ordered list of known statuses; add, rename, remove.
    - **Renaming** a status in the config does *not* rewrite tickets. Tickets keep their old status and appear
      under "Other" until moved. Say so inline in the panel.
    - **Removing** a status still used by tickets: warn with the count, e.g. "4 tickets have status *review*;
      they'll show under Other".
  - Validate the draft with the same rules as AT-037, ported as a small pure function (or compare the server's
    refusal). Show problems inline and disable Save while there are any.
- **Save**: `board.update`. On success, close; the `board` watch delivers the change. On refusal, keep the panel
  open with the message.
- **"Reset to defaults"**: writes the default config (asks first).
